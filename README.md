# HYOGO AREA LENS

兵庫県内の家賃と住環境を市区町村単位で比較する静的Webアプリです。引っ越し検討者が、希望間取り・上限家賃・通勤条件から候補市町を絞り込む用途を想定しています。

## 主な機能

- 兵庫県内 41 市町と神戸市 9 区の簡易地図表示
- 1K、1LDK、2LDK の家賃帯切り替え
- 家賃、家賃余力、総合、住環境、治安、商業、交通、災害、日常買物の指標切り替え
- 家賃上限、検索、通勤重視フィルタ
- 主要路線、おすすめ駅、激安スーパー候補のエリア別メモ
- ユニクロ、GU、家電量販店、居酒屋、飲食店の参考表示
- ブラウザ内に保存される市区町村別ユーザーコメント

## 使い方

ローカルサーバーで開くのがおすすめです。

```bash
python3 -m http.server 8765
```

その後、`http://localhost:8765` をブラウザで開きます。現在の標準表示は、ローカル画像と代表座標を使った簡易 SVG 地図です。ベースマップタイルは使っていません。ビルド手順は不要です。

## 本番公開

このアプリは静的サイトです。公開対象はリポジトリルート全体です。

- Build command: `exit 0`
- Publish directory: `.`
- Required runtime: なし

Netlify、Cloudflare Pages、Vercel、GitHub Pages などにそのまま配置できます。`index.html`、`app.js`、`styles.css`、`data/areas.js`、`assets/hyogo-map-bg.png` が同じ階層関係で配信される必要があります。

## コメント機能

ユーザーコメントはブラウザの `localStorage` に保存されます。現状では以下の仕様です。

- 同じブラウザ内ではリロード後も残る
- 別端末、別ブラウザ、他ユーザーとは共有されない
- サーバーやデータベースには送信されない

全ユーザーでコメントを共有したい場合は、Supabase、Firebase、自前APIなどのバックエンドに置き換える必要があります。

## 境界データのローカル保存

Geoshape の兵庫県（行政区域コード 28）のみの TopoJSON を取得して `data/hyogo-boundaries.topojson` に保存するための補助スクリプトがあります。現行 UI は簡易 SVG 地図を標準にしているため、境界 TopoJSON は本番化時の差し替え候補です。

```bash
./scripts/download-boundaries.sh
```

出力先:

- `data/hyogo-boundaries.topojson`: アプリが最初に参照する境界ファイル

全国データからの抽出が必要な場合は `scripts/extract-hyogo-boundaries.mjs` と `data/jp_city.c.topojson` を利用できます。

## データについて

現在の `data/areas.js` 内データと `app.js` 内の店舗・飲食店数は、UI と分析体験を確認するための参考推定データです。兵庫県内 41 市町を入れています。アプリ側では神戸市を 9 区に分割して表示します。家賃値・治安・災害・店舗有無・飲食店数は公式な実測値ではありません。

本番化する場合は、以下のデータソースに差し替える設計を想定しています。

- 治安: 兵庫県警または自治体の犯罪統計
- 家賃: 不動産ポータルの掲載データ、成約データ、募集賃料、駅距離、築年数、専有面積
- 収入: 市区町村別課税所得、統計ダッシュボード、e-Stat
- 商業施設: OpenStreetMap POI、Google Places API、自治体の商業統計
- 交通: 鉄道駅、バス停、GTFS、主要駅までの所要時間
- その他: 学校、病院、災害リスク、公園、人口動態、待機児童、地価

## 家賃データ設計

最低限ほしい項目:

- `municipality`: 市町村名
- `layout`: 1K、1LDK、2LDK など
- `medianRent`: 中央値家賃
- `p25Rent`: 安め物件の目安
- `p75Rent`: 高め物件の目安
- `sampleCount`: 集計物件数
- `updatedAt`: 集計日
- `source`: 出典

補正に使いたい項目:

- 駅徒歩分
- 築年数
- 専有面積
- 構造
- 駐車場有無
- 神戸三宮、大阪、姫路までの所要時間
